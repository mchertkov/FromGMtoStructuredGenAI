# Chapter 3 notebooks

These notebooks support Chapter 3, **Exact Elimination, Dynamic Programming, and Message Passing**.

1. `ch03_01_elimination_order_and_treewidth.ipynb` - variable elimination, fill-in, induced width, and contraction order.
2. `ch03_02_sum_product_on_trees.ipynb` - exact sum-product messages, marginals, and partition functions on trees.
3. `ch03_03_junction_tree.ipynb` - triangulation, clique trees, separators, and exact inference on a loopy graph.

All figures are written to `figs/` in PDF and PNG formats. Notebook markdown uses `$...$` and `$$...$$` for mathematics.
