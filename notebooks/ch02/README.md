# Chapter 2 notebooks

These notebooks support Chapter 2, "Graphical Models: Representations, Partition Functions, and First Examples."

1. `ch02_01_factorization_and_enumeration.ipynb` — local factors, exact normalization, marginals, MAP, and exact sampling.
2. `ch02_02_factor_graph_to_normal_factor_graph.ipynb` — parity constraints and FG-to-NFG conversion.
3. `ch02_03_conditional_independence.ipynb` — undirected separation, directed chains, forks, colliders, and explaining away.
4. `ch02_04_ising_chain_and_triangle.ipynb` — trees, loops, temperature, and frustration.
5. `ch02_05_gaussian_graphical_model.ipynb` — sparse precision, dense covariance, exact moments, and conditional independence.
6. `ch02_06_dynamic_graphical_model.ipynb` — path distributions, exact Markov propagation, and stochastic generation.

All notebooks save figures in `figs/` in both PDF and PNG formats. They are self-contained and use only NumPy, pandas, Matplotlib, NetworkX, and the Python standard library.
