# Chapter 9 companion notebooks

Loop corrections, generalized-loop enumeration, cluster cumulants, and tensor-network gauge invariance.

- `ch09_01_single_cycle_loop_correction.ipynb` - exact single-cycle correction beyond BP.
- `ch09_02_generalized_loop_enumeration.ipynb` - enumerate and inspect generalized loops.
- `ch09_03_cluster_cumulants.ipynb` - organize overlapping corrections through cumulants.
- `ch09_04_tensor_gauge_beyond_positivity.ipynb` - verify paired gauge invariance for positive, signed, and complex tensors and diagnose numerical conditioning.

All generated figures are saved in `figs/` as both PDF and PNG.
