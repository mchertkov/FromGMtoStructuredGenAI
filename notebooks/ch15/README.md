# Chapter 15 companion notebooks

Neuralization experiments that retain an explicit classical graphical-model reference.

- `ch15_01_bp_warm_start.ipynb` - learn a BP message initialization, then return to classical BP until convergence.
- `ch15_02_learned_bp_residual.ipynb` - compare direct prediction of the partition function with learning only the residual left by the Bethe/BP reference.

The chapter also formulates the next computational challenge: predict the exact fractional-BP parameter $\lambda_*$ on small labeled instances before attempting general neural loop resummation.

All generated figures are saved in `figs/` as both PDF and PNG.
