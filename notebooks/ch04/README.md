# Chapter 4 notebooks

These notebooks support Chapter 4, **Other Inference, Optimization and Learning Challenges**.

1. `ch04_01_map_temperature_and_conditioning.ipynb` - MAP, temperature, evidence, and conditioned marginals.
2. `ch04_02_gibbs_variational_principle.ipynb` - exact free-energy/KL identity and variational optimization.
3. `ch04_03_exact_decimation_sampling.ipynb` - exact independent generation by sequential conditionals.
4. `ch04_04_exponential_family_learning.ipynb` - moment matching and maximum-likelihood learning.

All figures are saved to `figs/` as both PDF and PNG. The notebooks reuse the small Ising models introduced in Chapter 2.
